# Simple Automation Handbook

A beginner-friendly manual on safe, everyday automation: sorting downloads,
renaming files, setting up bill reminders, and saving webpages — using only
built-in tools and tiny scripts you can read and trust.

---

## What's inside

- `docs/` — beginner manuals in Markdown (read them here, or in the static HTML
  site under `static/`).
- `scripts/` — tiny, auditable Python scripts for each task. Each one works on
  copies by default and never touches your originals unless you explicitly ask
  it to.
- `static/checklist.html` — a printable checklist you can print and tick off by
  hand.
- `tests/` — small tests that prove the scripts behave safely.

## How to use this handbook

1. **Read the safety page first** (`docs/safety.md`). The golden rule: test on
   copies, never move originals.
2. Pick a task (sorting downloads, renaming files, bill reminders, saving
   webpages) and read its guide in `docs/`.
3. Run the matching script in `scripts/` against a copy of your files first.
4. When you're confident, run it on your real files — or keep using copies
   forever. Either way is fine.
