# Overview

Welcome to the Simple Automation Handbook. This is a beginner's guide to safe,
everyday automation using tools you already have and tiny scripts you can read
end-to-end.

## Who this is for

You don't need to be a programmer. You don't need to have used the command
line before. If you can copy and paste, you can use this handbook.

It's written for anyone who wants their computer to do a little less drudgery:
sorting downloads, renaming files, remembering bills, saving pages to read
later. Plain English, step by step, never condescending.

## What's in the manual

| Guide | What it does |
|-------|-------------|
| [Safety first](safety.md) | The rules to follow before you automate anything |
| [Sorting your downloads](sorting-downloads.md) | Tidy your Downloads folder by file type |
| [Renaming files](renaming-files.md) | Bulk-rename messy files with prefixes, numbers, and more |
| [Bill reminders](bill-reminders.md) | Get reminded when bills are due |
| [Saving webpages](saving-webpages.md) | Save pages to read offline |

Each guide has a matching script in `scripts/`. Every script works on copies
first and never touches your originals unless you explicitly ask.
