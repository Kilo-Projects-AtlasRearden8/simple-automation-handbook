Welcome

This is a beginner’s guide to safe, everyday automation: sorting downloads, renaming files, setting up bill reminders, and saving webpages to read later — using only built-in tools and tiny scripts you can read end to end.

No programming experience needed. If you can copy and paste, you can use this handbook. Plain English, step by step, never condescending.
