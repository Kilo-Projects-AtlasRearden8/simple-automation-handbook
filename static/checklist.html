Simple Automation Checklist

A printable safety-first checklist for everyday automation.
Published by Asdale Dynamics, LLC (Indiana, formed October 2026).
Credit: Dylan Asdale, registered nurse turned AI author and founder of Asdale Dynamics, LLC.

Golden rule: Test on copies, never move originals. Every script works on a copy by default. Only point it at your real files once you're sure it does what you expect.

1. Before you start

  • Read docs/safety.md — the rules to follow before automating anything.
  • Open and read the script you plan to use (in scripts/) so you understand what it does.
  • Make a test copy of the folder you want to work on (e.g. Downloads Test).

2. Sorting downloads

  • Run on the test copy first: python3 scripts/sort_downloads.py <test-folder> --dry-run
  • Check that files landed in the right folders (Documents, Images, Audio, Video, Archives, Installers, Other).
  • Run for real on the test copy: python3 scripts/sort_downloads.py <test-folder>
  • When confident, run on your real folder (or keep using copies).

3. Renaming files

  • Make a test copy of the folder with messy file names.
  • Preview changes (no files touched): python3 scripts/rename_files.py <test-folder> --prefix your-prefix --dry-run
  • Review the old → new name list carefully.
  • Rename for real: python3 scripts/rename_files.py <test-folder> --prefix your-prefix --apply
  • Open the folder and confirm the names look right.

4. Bill reminders

  • Create bills.txt with lines like: Electric | 2026-11-05 | $87.30
  • Run the reminder: python3 scripts/bill_reminders.py bills.txt
  • Note any upcoming (within 7 days) or overdue bills.
  • Set a weekly reminder (phone/calendar) to run the script again.

5. Saving webpages

  • Copy the URL of the page you want to keep for offline reading.
  • Run: python3 scripts/save_webpage.py <URL> <output-folder>
  • Open the saved .html file in your browser to confirm it looks right offline.
  • File the saved page into a topic folder (Recipes, Research, Fun, etc.).
Remember: Nothing leaves your computer. No accounts, no API keys, no personal data needed. If anything feels off, stop and read the script.
